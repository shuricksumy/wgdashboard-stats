First release. Per-peer WireGuard traffic reports for [WGDashboard](https://github.com/WGDashboard/WGDashboard), built on the traffic snapshots WGDashboard already records, read-only.

### Features
- Any date range with presets (this month, last month, last 30 days, this year)
- Sent / received / total per peer and overall, with each peer's share
- Daily stacked chart; tap a peer to see only its days
- Restricted and deleted peers included
- CSV export
- Gaps when WGDashboard wasn't recording are spread out and marked *estimated* instead of showing as one spike
- Light / dark / auto theme, phone-friendly layout, bookmarkable URLs
- `BASE_PATH` to serve under a path such as `/wgstat/`

### Correctness
Snapshots are processed in insertion order, so clock changes (DST) can't double-count; float-noise dips are ignored; real counter resets are detected; cleared or vacuumed transfer tables are handled. Each case is covered by tests.
