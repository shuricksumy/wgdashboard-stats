### New
- **In / out vs Combined** switch on the daily chart: combined shows sent + received as one bar per day. The choice is remembered and kept in the URL (`view=total`).
- Estimated usage (periods when WGDashboard wasn't recording) is drawn with diagonal stripes, so it can't be mistaken for measured traffic.

### Improved
- Buttons, tabs, date presets and the theme switch look clearly tappable; sortable table headers show arrows; peer names are styled as links.
- Phone layout: date fields no longer overflow on iPhone and their dates are centered; the peer table gives names more room and shortens very long names with "…".
- Dependencies updated (FastAPI 0.162, Uvicorn 0.54, httpx 0.28, pytest 9.2).

### Project
- Single `main` branch: every push publishes `:latest`; releases add `X.Y.Z` and `X.Y` tags. The `:dev` image is no longer published.

```
ghcr.io/shuricksumy/wgdashboard-stats:1.1.0
ghcr.io/shuricksumy/wgdashboard-stats:1.1
ghcr.io/shuricksumy/wgdashboard-stats:latest
```
